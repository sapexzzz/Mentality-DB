# Mentality DB v0.20.4 (18.03.2026)

## Главное в версии

- Новый красивый и удобный экспорт через отдельное окно настроек экспорта.
- Надёжный поиск по городу в обычном и расширенном поиске.
- Глобальные горячие клавиши редактирования (`Ctrl+A/Z/Y/X/C/V`).

## Новый экспорт

Кнопка экспорта открывает окно, где можно выбрать:
- **Объём**: вся база или одна карточка
- **Формат**: `mtb` или `csv`

Для режима "одна карточка" доступен список карточек.

## Поиск

### Обычный поиск
- Ищет по всем полям карточки
- Нечувствителен к регистру
- Учитывает варианты старых данных для города

### Расширенный поиск
- Ищет по выбранным полям
- Нечувствителен к регистру
- Для телефона использует сравнение по цифрам

## Горячие клавиши

- `Ctrl+A` — выделить всё
- `Ctrl+Z` — undo
- `Ctrl+Y` — redo
- `Ctrl+X` — cut
- `Ctrl+C` — copy
- `Ctrl+V` — paste

## Хранение старых версий

Старые версии кода и документов сохраняются в папке `old_data`.
# Mentality DB v0.20.3 (18.03.2026)

## Что обновлено

- Поиск по городу исправлен в обычном и расширенном режиме.
- Поиск нечувствителен к регистру (`Rouen` = `rouen`).
- Обычный поиск теперь запускается только вручную: кнопка-лупа или Enter.

## Обычный поиск

Работает по всем полям карточки и применяет фильтр только после явного запуска.

Запуск:
- `Enter` в поле поиска
- кнопка `🔎` рядом со строкой

## Расширенный поиск

- Ищет по отдельным полям с нормализацией текста.
- Enter в полях перемещает фокус, на последнем поле запускает поиск.

## Архив старых версий

Все старые версии сохраняются в `old_data`:
- старые `main.py`
- старые `README`
- старые `CHANGELOG`
