# Mentality DB v0.20.1 (18.03.2026)

Приложение для локального хранения контактных данных с шифрованием, импортом, экспортом и резервным копированием.

## Главное в версии 0.20.1

- Обычный поиск работает по всем основным полям карточки.
- Расширенный поиск показывает только найденные карточки и подсвечивает их.
- Исправлены кастомные диалоги `CTk`, включая окно результата резервной копии.
- Старые версии скрипта и документации автоматически складываются в папку `old_data`.

## Поиск

### Обычный поиск
Ищет по:
- имени RU
- фамилии RU
- имени EN
- фамилии EN
- стране
- городу
- адресу
- телефону

### Расширенный поиск
- поиск по отдельным полям
- `Enter` переводит к следующему полю
- на последнем поле `Enter` запускает поиск
- после поиска показываются только найденные карточки

## Архив старых версий

Все старые версии хранятся в папке `old_data`:
- старые `README`
- старые `CHANGELOG`
- старые версии `main.py`

## Запуск

```bash
python main.py
```

или

```bash
./run.sh
```
# 🧠 Mentality DB v0.20.0 (18.03.2026)

Приложение для безопасного хранения контактных данных с шифрованием и резервным копированием.

## 📦 Установка

```bash
pip install customtkinter pillow cryptography
```

## 🚀 Запуск

```bash
python main.py
# или
./run.sh
```

## ✨ Возможности

- 🔐 Шифрование AES-256 всех персональных данных
- 📂 Создание, редактирование, удаление контактов
- 📷 Фотографии к контактам
- 🗑 Корзина с восстановлением
- 📤 Экспорт в .mtb и CSV
- 📥 Импорт из .mtb
- 💾 Резервное копирование БД
- 📋 Дублирование контактов
- 📅 История изменений контакта
- 🔍 Быстрый и расширенный поиск с подсветкой
- ⌨️ Навигация по Enter (следующее поле / сохранение)
- 🌐 Мультиязычность (RU/EN) из JSON файлов
- 🎨 Тёмная и светлая тема
- 🪟 Единый стиль всех диалоговых окон

## 📁 Структура

```
mentality_db/
├── main.py              # Основной код
├── config.json          # Конфигурация
├── run.sh               # Скрипт запуска
├── languages/           # Языковые файлы (ru.json, en.json)
└── exports/             # Экспорт, CSV, бэкапы
```

## 🌐 Языки

Языки загружаются из папки `languages/` (JSON файлы). Для добавления нового языка создайте файл `xx.json` по образцу существующих.

## 📄 Версионирование

Файлы CHANGELOG и README создаются с датой и версией в названии.
