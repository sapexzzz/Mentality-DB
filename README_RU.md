# Mentality DB v0.20.6 (18.03.2026)

## Что обновлено

- Поиск по городу исправлен и работает стабильнее.
- Область поиска в настройках теперь мультивыборная (можно выбрать сразу несколько полей).
- Изменения в настройках применяются сразу и не закрывают окно.
- Убраны лишние параметры настроек экспорта и лимита бэкапов.

## Поиск

### Базовый поиск

- Запускается по `Enter` или кнопке лупы.
- В режиме `live` срабатывает при вводе.
- Учитывает выбранные поля из настроек.
- Для совместимости со старыми данными проверяет связку `город + адрес`.

### Расширенный поиск

- Работает по отдельным полям, включая город, адрес и телефон.
- Результаты подсвечиваются в списке.

## Настройки

Доступны:
- Theme
- Language
- Search trigger (`manual` / `live`)
- Grid columns
- Date format (`iso` / `ru` / `us`)
- Unsaved action (`ask` / `save` / `discard`)
- Backup before import (`true` / `false`)
- Search scope (мультивыбор полей)

Удалены:
- Default export format
- Default export scope
- Max backups

## Экспорт

Через одно окно `Экспорт`:
- формат: `mtb` или `csv`
- объём: вся база или выбранные карточки
- поддержан экспорт одной или нескольких карточек

## Архив

Старые версии скрипта и документации находятся в `old_data`.
