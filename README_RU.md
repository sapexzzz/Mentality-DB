# Mentality DB v0.20.2 (18.03.2026)

Локальная база контактов с шифрованием, импортом/экспортом, резервным копированием и расширенным поиском.

## Что исправлено в этой версии

- Поиск по адресу и телефону работает в обычном и расширенном режимах.
- Обычный поиск теперь охватывает все текстовые поля карточки.
- Расширенный поиск корректно фильтрует и подсвечивает найденные карточки.
- Новые карточки не создаются в базе до явного сохранения.
- Выход из новой карточки без сохранения не оставляет пустые записи.
- Диалоги приложения работают без ошибок отображения и используют тему интерфейса.

## Поиск

### Обычный
Ищет по:
- имя RU/EN
- фамилия RU/EN
- страна
- город
- адрес
- телефон

### Расширенный
- поиск по отдельным полям
- Enter переключает фокус на следующее поле
- Enter на последнем поле запускает поиск
- результаты подсвечиваются и отображаются как фильтр списка

## Политика хранения старых версий

Старые версии всегда хранятся в папке `old_data`:
- предыдущие `main.py`
- предыдущие `README`
- предыдущие `CHANGELOG`

## Запуск

```bash
python main.py
```

или

```bash
./run.sh
```
