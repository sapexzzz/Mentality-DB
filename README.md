# 🗂 Mentality DB

> Локальная зашифрованная база контактов с графическим интерфейсом  
> Версия: **0.20.6** · Python 3.10+ · CustomTkinter · SQLite

---

## 📋 О проекте

**Mentality DB** — настольное приложение для хранения личной адресной книги.  
Все данные хранятся локально в зашифрованной базе SQLite (Fernet AES-128-CBC).  
Поддерживает фотографии, поиск, экспорт/импорт, резервные копии и сменную тему оформления.

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🔒 Шифрование | Все поля карточки и фото зашифрованы ключом Fernet |
| 👤 Карточки | Имя (RU/EN), страна, город, адрес, телефон, фотографии |
| 🔍 Поиск | Базовый (по строке) и расширенный (по полям); мультиязычный, регистронезависимый |
| 📤 Экспорт | MTB (JSON hex-blob) и CSV; по всей базе или выбранным карточкам |
| 📥 Импорт | Слияние с существующими данными с возможностью замены |
| 💾 Бэкап | Ручное создание резервной копии БД |
| 🌍 Локализация | Русский и English; файлы в `languages/` |
| 🎨 Темы | Dark / Light |
| 🗑 Корзина | Удалённые контакты сначала попадают в корзину |
| 📋 Дубликат | Быстрое копирование карточки |
| 📅 История | Дата создания и последнего обновления |

## 🚀 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/mentality-db.git
cd mentality-db

# Установить зависимости
pip install customtkinter cryptography Pillow

# Запуск
python main.py
```

Или через `run.sh`:

```bash
bash run.sh
```

## 📂 Структура проекта

```
mentality_db/
├── main.py              # Основной файл приложения
├── config.json          # Настройки (создаётся автоматически)
├── database.db          # База данных (создаётся автоматически)
├── .mentality_key       # Ключ шифрования (НЕ распространяйте!)
├── run.sh               # Скрипт быстрого запуска
├── languages/
│   ├── ru.json          # Русская локализация
│   └── en.json          # English localization
├── exports/             # Папка экспорта (MTB, CSV, бэкапы)
└── old_data/            # Архив предыдущих версий
```

> ⚠️ **ВАЖНО**: Файл `.mentality_key` — единственный ключ к вашим данным.  
> Без него расшифровка невозможна. Сделайте его резервную копию отдельно.

## 🖥 Использование

### Создание карточки

1. Нажмите **➕ Создать карточку** в главном окне.
2. Заполните поля (Tab/Enter — переход между полями).
3. Нажмите **💾 Сохранить изменения**.

### Поиск

- **Базовый**: введите запрос в строку поиска, нажмите Enter или 🔎.
- **Расширенный**: нажмите **🔍 Расширенный**, задайте условия по отдельным полям.

В настройках можно выбрать режим поиска (`manual` / `live`) и набор полей для поиска.

### Экспорт

Нажмите **📤 Экспорт**, выберите:
- **Формат**: `MTB` (полный с фото) или `CSV` (текст без фото)
- **Объём**: вся база или выбранные карточки

### Импорт

Нажмите **📥 Импорт**, выберите файл `.mtb`.  
При совпадении имён появится запрос: заменить или создать копию.

## 🔧 Настройки

| Параметр | Значения | По умолчанию |
|---|---|---|
| Тема | Dark / Light | Dark |
| Язык | ru / en | ru |
| Запуск поиска | manual / live | manual |
| Колонок в списке | 3–6 | 5 |
| Формат даты | iso / ru / us | iso |
| При несохранённых | ask / save / discard | ask |
| Бэкап перед импортом | true / false | true |
| Область поиска | мультивыбор полей | все поля |

> Смена языка мгновенно перезагружает интерфейс.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+A` | Выделить всё в поле |
| `Ctrl+Z` | Отмена |
| `Ctrl+Y` | Повтор |
| `Enter` (в карточке) | Переход к следующему полю |
| `Enter` (последнее поле) | Сохранить карточку |
| `Esc` | Назад / выйти из режима экспорта |
