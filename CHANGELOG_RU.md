# Mentality DB - Changelog v0.20.2 (18.03.2026)

## Исправления поиска

- Обычный поиск теперь покрывает все поля карточки: имя/фамилия RU, имя/фамилия EN, страна, город, адрес, телефон.
- Добавлена нормализация телефонного поиска: поиск по цифрам работает даже если в телефоне есть пробелы, скобки, дефисы и знак `+`.
- Расширенный поиск исправлен для адреса и телефона: значения корректно приводятся к тексту и сравниваются без ошибок типов.
- После расширенного поиска список реально фильтруется найденными карточками и подсвечивается.

## Исправления создания карточек

- Новая карточка больше не записывается в базу до нажатия кнопки сохранения.
- Если выйти из карточки без сохранения, пустая карточка не появляется в списке.

## Тема интерфейса

- Очистка корзины и выбор режима экспорта снова работают через тематизированные диалоги приложения.
- Исправлено создание кастомных диалогов: исключение `grab failed: window not viewable` устранено.

## Архивация

- Предыдущие версии `README`, `CHANGELOG` и снимок скрипта сохранены в `old_data`.
