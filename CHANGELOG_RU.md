# Mentality DB - Changelog v0.20.3 (18.03.2026)

## Поиск

- Исправлен поиск по городу в обычном и расширенном поиске.
- Добавлена более надежная нормализация текста (`NFKC` + `casefold` + trimming spaces), чтобы поиск корректно находил значения вроде `Rouen` при вводе `rouen`.
- Поиск по телефону в обоих режимах продолжает работать по цифрам независимо от форматирования.

## Режим запуска обычного поиска

- Обычный поиск больше не запускается при каждом вводе символа.
- Поиск запускается только:
  - по клавише `Enter` в строке поиска;
  - по кнопке-лупе рядом со строкой поиска.

## Поведение фильтров

- Добавлен отдельный "применённый" поисковый запрос для обычного поиска, чтобы результаты менялись только после явного запуска поиска.
- При переключении режима (База/Корзина) строка и фильтр обычного поиска сбрасываются.

## Архивация

- Предыдущие `README`, `CHANGELOG` и снимок скрипта перемещены в `old_data`.
