# Mentality DB - Changelog v0.20.5 (18.03.2026)

## Экспорт

- Полностью обновлено окно экспорта.
- Добавлен выбор объёма:
  - `Вся база`
  - `Одна или несколько`
- Добавлен экспорт нескольких выбранных карточек (не только одной и не только всех).
- Удалена отдельная кнопка CSV из главного меню: логика экспорта CSV перенесена в единое окно экспорта.
- Добавлены дефолтные настройки экспорта (формат и объём).

## Поиск

- Усилен поиск по городу в обычном и расширенном поиске.
- Сохранён fallback для старых данных, где город мог оказаться в адресе.
- Поиск учитывает регистр-независимое сравнение с нормализацией текста.
- Добавлены настройки области поиска (`all` / `names`) и режима запуска (`manual` / `live`).

## Горячие клавиши

- Поддержка `Ctrl+A`, `Ctrl+Z`, `Ctrl+Y`, `Ctrl+X`, `Ctrl+C`, `Ctrl+V` для полей ввода приложения.

## Настройки

Добавлены важные настройки:
- запуск поиска (`manual`/`live`)
- область поиска (`all`/`names`)
- количество колонок списка карточек
- формат даты
- поведение при несохранённых изменениях (`ask`/`save`/`discard`)
- формат экспорта по умолчанию
- объём экспорта по умолчанию
- бэкап перед импортом (`true`/`false`)
- лимит хранимых бэкапов

## Безопасность данных

- Добавлена проверка несохранённых изменений при закрытии карточки.
- Добавлена ротация бэкапов (хранение последних N копий).

## Архивация

- Предыдущие README/CHANGELOG и снимок скрипта перенесены в `old_data`.
